## Learning Approach

I'm using this repository to **practice by writing code**, not just watching tutorials.

My general process is:

```text
Learn
  ↓
Understand
  ↓
Try it myself
  ↓

  ↓

  ↓
Improve
```

When I use documentation, search, or AI to understand syntax or a concept, the goal is to understand and implement the idea myself rather than simply copy a complete solution.
